FULLMYSQL_DATABASE_URL=${db-mysql-sfo3-62654.DATABASE_PRIVATE_URL}
FULLMYSQL_DB_CA_CERT=${db-mysql-sfo3-62654.CA_CERT}

FULLMYSQL_UPLOAD_LIMIT_MB=96
FULLMYSQL_WORKER_POLL_SECONDS=5
FULLMYSQL_WORKER_RESTART_SECONDS=5

Set FULLMYSQL_WORK_TOKEN and FULLMYSQL_HOME_TOKEN as ENCRYPTED runtime secrets.
Do not wrap the token values in JSON, quotes, braces, or angle brackets.
FULLMYSQL_API_TOKENS_JSON remains supported only as a backward-compatible fallback.
If private VPC is not enabled yet, DATABASE_URL may be used temporarily instead of DATABASE_PRIVATE_URL.
Do not create a separate App Platform Worker component for this edition.

ChatGPT Google Sheet bridge (v7.0.124+):

Preferred transport — Google Apps Script Web App (no service-account JSON):
FULLMYSQL_CHATGPT_SHEET_ENABLED=0
FULLMYSQL_CHATGPT_SHEET_REQUIRED=0
FULLMYSQL_CHATGPT_SHEET_TRANSPORT=APPS_SCRIPT
FULLMYSQL_CHATGPT_SHEET_ID=1kZQg_dQ79Jagg7hkBKs4YX33QBy9ByrDvq5KActCgwI
FULLMYSQL_CHATGPT_BRIDGE_ACTIVE_SOURCE=HYBRID_SQLITE
FULLMYSQL_APPS_SCRIPT_WEB_APP_URL=<production Apps Script /exec URL>
FULLMYSQL_APPS_SCRIPT_WEBHOOK_SECRET=<encrypted high-entropy shared secret>

Apps Script setup:
1. Follow docs/GOOGLE_APPS_SCRIPT_BRIDGE.md.
2. Store the same secret in Apps Script Script Properties as FULLMYSQL_WEBHOOK_SECRET.
3. Store FULLMYSQL_APPS_SCRIPT_WEBHOOK_SECRET in DigitalOcean as an ENCRYPTED secret.
4. Set FULLMYSQL_CHATGPT_SHEET_ENABLED=1.
5. Keep FULLMYSQL_CHATGPT_SHEET_REQUIRED=0 for the first smoke-test publish.
6. Verify BRIDGE_STATUS=PASS and MYSQL_SOURCE_STATUS batch/readback parity.
7. Then set FULLMYSQL_CHATGPT_SHEET_REQUIRED=1 so every future READY batch must publish/read back before the outer pipeline can complete.
8. Keep FULLMYSQL_CHATGPT_BRIDGE_ACTIVE_SOURCE=HYBRID_SQLITE until FULL MYSQL analysis parity is approved; then change it to FULL_MYSQL.

Legacy optional transport — Service Account:
FULLMYSQL_CHATGPT_SHEET_TRANSPORT=SERVICE_ACCOUNT
FULLMYSQL_GOOGLE_SERVICE_ACCOUNT_JSON=<encrypted Google service-account JSON>

Never commit the Apps Script webhook secret or service-account JSON to GitHub.


# v7.0.104 Admin Console browser sessions
# Optional but recommended encrypted secret. If omitted, the server derives a
# signing key from the configured API tokens, so rotating API tokens also
# invalidates all browser admin sessions.
FULLMYSQL_ADMIN_SESSION_SECRET=<ENCRYPTED_RANDOM_SECRET>


# v7.0.106 Admin Console ID/password login
# Login ID is not secret; defaults to "admin" when omitted.
FULLMYSQL_ADMIN_LOGIN_ID=admin

# Recommended: store as an ENCRYPTED runtime secret in DigitalOcean.
# When configured, browser Admin login uses this password and no longer accepts
# the legacy API token as a browser password.
FULLMYSQL_ADMIN_PASSWORD=<ENCRYPTED_ADMIN_PASSWORD>

# Optional stronger alternative to FULLMYSQL_ADMIN_PASSWORD.
# Format: pbkdf2_sha256$iterations$salt_b64$digest_b64
# If FULLMYSQL_ADMIN_PASSWORD_HASH is set, it takes priority over the plaintext
# encrypted secret above.
FULLMYSQL_ADMIN_PASSWORD_HASH=<OPTIONAL_PBKDF2_HASH>

# Migration behavior:
# If neither FULLMYSQL_ADMIN_PASSWORD nor FULLMYSQL_ADMIN_PASSWORD_HASH is set,
# Admin ID "admin" (or FULLMYSQL_ADMIN_LOGIN_ID) can temporarily use an existing
# admin API token as the browser password. This fallback is disabled
# automatically as soon as a dedicated password or password hash is configured.
