FULL MYSQL v7.0.36 GitHub Patch

Purpose:
- Diagnose all current Quick Check cost-related QA holds in one HTTPS call.
- Separate safe cost-lineage repairs from cases that truly need new UOM/conversion evidence.

Endpoint:
GET /v1/diagnostics/cost-holds

Optional filters:
- ?upc=<EAN/UPC>
- ?family_id=<family_id>

Read-only evidence sources:
1) Current quick_check_current QA_HOLD rows.
2) Confirmed Family -> Article identity.
3) Receipt movement 101/107/109 valuation rows.
4) Official Frozen / TX Seafood ABC / Live-Fresh cost rows.
5) Raw On-Hand explicit Cost + explicit cost-specific UOM.
6) Existing authoritative derived cost.
7) Exact Article Manual UPC row / pack text.

Classifications for CURRENT_COST_MISSING include:
- SAFE_RECEIPT_VALUATION_REPAIR_CANDIDATE
- SAFE_OFFICIAL_COST_REPAIR_CANDIDATE
- SAFE_OH_COST_FALLBACK_REPAIR_CANDIDATE
- RECEIPT_ROWS_WITHOUT_VALID_VALUATION
- OFFICIAL_COST_WITHOUT_EXPLICIT_UOM
- OH_COST_WITHOUT_EXPLICIT_SUPPORTED_UOM
- NO_AUTHORITATIVE_COST_EVIDENCE

Classifications for COST_TO_SELLING_UOM_UNRESOLVED include:
- DIRECT_COST_UOM_EQUALS_SELLING_UOM
- SERVING_CONVERSION_REBUILD_CANDIDATE
- PACK_CONVERSION_EVIDENCE_NEEDED
- AUTHORITATIVE_COST_UOM_MISSING
- COST_UOM_SELLING_UOM_MISMATCH

Important:
- DIRECT_COST_UOM_EQUALS_SELLING_UOM means cost-per-selling can use factor 1
  directly for calculation. It does NOT set Base/Inventory UOM.
- No cross-UOM conversion is inferred from description or package text alone.
- This release performs no mutations.
