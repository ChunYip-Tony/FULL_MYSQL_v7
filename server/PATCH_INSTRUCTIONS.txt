- Make GET /v1/diagnostics/cost-holds use the same gates as official-cost repair.

Why:

  remained CURRENT_COST_MISSING.

  actual executable repair path.

Read-only diagnostic changes:
For official report cost evidence, a row is SAFE only when:
1) positive official_cost exists
2) source row can resolve to the target Family through:
   - existing family_id
   - confirmed article_id -> Family
   - source article_number -> Family
   - existing upc_id -> confirmed Article -> Family
3) cost_uom_code resolves to dim_uom
4) an Article anchor is available for article_cost_observation
