FULL MYSQL Secure API Architecture
Version: 7.0.111 Single-Service Edition

Current runtime:
- Existing public Web App remains available at /app during V2 transition.
- Web App V2 test UI is available at /app/v2.
- V2 top-level functions: CORE, ORDERING, PI.
- V2 data/API contracts remain under /v1/app/v2.

Web App V2 rules:
- CORE: Search -> Family/UPC -> Price / Ordering.
- CORE Ordering is Family Article level even when entered from a UPC.
- Price includes Price vs Sales trend using completed canonical supported dates only.
- Missing source dates are ignored, never zero-filled.
- Promotion = SALE only; TPR is not Promotion.
- Historical SALE periods identify Weekend / Weekly / Other patterns.
- Main ORDERING scans FRESH only or FROZEN only.
- Main ORDERING eligibility: active selling in latest 28 supported completed POS dates AND DOS < 7.
- Negative Effective OH is displayed but ordering calculations use max(OH,0).
- Suggested quantity covers demand through the day before next-next delivery.
- Price and Ordering are analysis-only; no save/submit workflow.
- PI is inventory-owner-aware and writes authoritative True Stock.
- True Stock stays active until superseded by a later accepted OH upload.
