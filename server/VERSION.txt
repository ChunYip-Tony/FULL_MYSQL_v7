Version: 7.0.109 Single-Service Edition

Current runtime:
- Existing public Web App remains available.
- Isolated Web App V2 read-only data contracts are now available under /v1/app/v2.
- V2 Search, Family Article, UPC, Price Analysis, and Ordering Analysis contracts implemented.
- V2 UI has not yet replaced the current Web App.

Web App V2 data rules:
- 7D / 28D use latest completed canonical data-supported POS dates.
- Missing source dates are ignored and never counted as zero.
- Velocity denominator = supported day count only.
- Promotion = Price Type SALE only.
- TPR is not Promotion.
- Weekend Promotion = Friday through Sunday.
- Weekly Promotion = Thursday through following Friday.
- Price vs Sales trend uses completed supported data days.
- Ordering analysis is read-only; nothing is saved or submitted.
- Ordering default date = current business date.
- Expected delivery default = observed receipt pattern when sufficiently stable.
- Suggested order covers forecast usage through next-next delivery minus Effective OH.
- No invented promotion uplift when matching SALE history is unavailable.

V2 endpoints:
- GET /v1/app/v2/search
- GET /v1/app/v2/family/{family_key}
- GET /v1/app/v2/upc/{upc}
- GET /v1/app/v2/upc/{upc}/price
- GET /v1/app/v2/upc/{upc}/ordering

Legacy Admin remains in source during transition but is not part of the Web App V2 target architecture.
