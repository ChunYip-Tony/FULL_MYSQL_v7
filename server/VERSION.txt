v7.0.134 No-login Web Upload Status:
- Public Fish Market Web App includes Upload as a fifth main tab.
- No Admin login, browser session, or API token is required for raw file upload.
- No login is required to view active upload or readiness status.
- Users can select or drag/drop multiple raw files into one ingest batch.
- Supported browser upload extensions: XLSX, XLS, XLSM, CSV, TXT, TSV.
- Browser upload reuses the same canonical begin_batch -> add_file -> commit_batch -> worker -> Phase2C -> Phase3 -> Quick Check pipeline used by the Windows client.
- Current Batch shows each file's filename, detected source type, raw row count, date coverage and ingest status.
- Batch readiness shows Phase2C, Phase3, and Quick Check READY/HOLD counts.
- Recent Uploads shows recent batches and per-file ingest/readiness information without login.
- Failed pre-commit Web uploads automatically abort the incomplete batch to prevent an API_UPLOADING lock.
- Browser guardrails remain: same-origin/cross-site protection, existing file-size limit, 40-file batch limit, supported-extension allowlist, and one-active-batch serialization.
- Existing Bearer-token Windows client endpoints remain available but are optional.
