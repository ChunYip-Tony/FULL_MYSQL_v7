Version: 7.0.133 Single-Service Edition

v7.0.133 No-client Web Upload:
- Public Fish Market Web App now includes a fifth main tab: Upload.
- No Admin login is required for this upload-only workflow.
- Users can select or drag/drop multiple raw files into one ingest batch.
- Supported browser upload extensions: XLSX, XLS, XLSM, CSV, TXT, TSV.
- Browser upload reuses the same begin_batch -> add_file -> commit_batch -> worker pipeline used by the Windows client.
- The Upload page displays filename, detected source type, raw row count, date coverage, Phase 2C status, Phase 3 status, and final Quick Check READY / QA HOLD state.
- Guardrails: same-origin browser writes, existing per-file upload size limit, 40-file batch limit, supported-extension allowlist, and the existing one-active-batch rule.
- Existing Bearer-token client upload endpoints remain unchanged and available.
- No-client upload does not expose Admin, maintenance, price-change, or database mutation endpoints beyond ingest batch creation/file upload/commit.
